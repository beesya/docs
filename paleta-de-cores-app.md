# Paleta de Cores

## Cores Principais

| Cor | Hex | Uso recomendado |
|------|-----|-----------------|
| 🟨 Amarelo Primário | `#F7C948` | Cor principal da marca, destaques, CTAs e elementos de maior atenção. |
| 🟧 Amarelo Ouro | `#F8AB1A` | Hover, variações de destaque e elementos secundários da identidade. |
| 🟩 Verde | `#2E7D32` | Sucesso, saúde, indicadores positivos e elementos relacionados à nutrição. |
| ⬛ Preto | `#1E1F1F` | Textos principais, títulos, ícones e elementos de alto contraste. |
| ⬜ Off White | `#E4E1D8` | Fundo, superfícies claras, cartões e áreas de respiro visual. |

## Recomendações

- Utilize o **Amarelo Primário** como cor predominante da identidade.
- O **Amarelo Ouro** deve complementar o amarelo principal sem competir com ele.
- O **Verde** deve representar informações positivas, naturais ou relacionadas à saúde.
- O **Preto** deve ser utilizado para garantir excelente legibilidade.
- O **Off White** funciona como fundo neutro para manter a interface leve.

## CSS

```css
:root {
  --color-primary: #F7C948;
  --color-secondary: #F8AB1A;
  --color-success: #2E7D32;
  --color-text: #1E1F1F;
  --color-background: #E4E1D8;
}
```
